# High Temp Pre-Filters
This type pocket filter is designed for high temperature furnace, high capacity air filtration, hydrofluoric acid and alkali, high humidity area, etc. All materials in stainless steel 304 without oil
Detailed information:
Type: Panel,washable
Frame material: Stainless steel 304
Filter media: Stainless steel 304
Max. Working temp: 110°C/250°C/385°C
Filter class: G1/G2/G3
Standard size: 596 x 596mm, 594 x 490mm, 592 x 287mm
Standard depth: 22/46/69mm
Benefits of production:
1. Whole set stainless steel 304
2. Easy installation
3. Washable
Benefits of our factory:
1. Buyer can monitor working schedule in real time
2. Complete set testing devices
3. Clean workshop
