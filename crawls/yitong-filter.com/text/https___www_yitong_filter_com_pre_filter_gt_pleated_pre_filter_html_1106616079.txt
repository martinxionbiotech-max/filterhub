# GT Pleated Pre-Filter
This type pocket filter is designed as first stage air filter of gas turbine filtering system, also widely used in air compressor, engines, commercial building, HVAC.
Detailed information:
Type: Panel, pleated, disposable
Frame material: Paper
Filter media: Synthetic fibre / Cotton
Filter class: G3/G4
Initial pressure drop: 70Pa
Standard size: 594 x 594mm
Standard depth: 46/69/95/102mm
