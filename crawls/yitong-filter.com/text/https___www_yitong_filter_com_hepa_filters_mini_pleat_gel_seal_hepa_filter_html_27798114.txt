# Mini Pleat Gel Seal HEPA Filter
Gel type HEPA H13/H14 filters designed for easy installation as terminal filter in clean room.
Micro glass fibre paper as filter media with stable performance and longer service life.
The biggest difference is Gel sealant glue which looks like jelly. This can ensure 0% leakage from sides, also environment friendly.
Detailed information:
Type: Mini Pleat
Frame material: Galvanized sheet, Anodised extruded aluminum, SUS304
Filter media: Micro glass fibre paper
Slot gasket: Gel sealant glue
Filter class: H13/H14 (EN1822)
Initial resistance: 220 ~ 250 Pa
Standard size: 610 x 610mm,610 x 305mm, 450 x 450mm
Standard depth: 69/90/105mm
